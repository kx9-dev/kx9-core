# Security policy

## Report privately
Email **dev@kx9.tech** with affected repository/version, reproduction steps,
impact and a minimal non-sensitive example. Do not post credentials, private
RPC URLs, signed transactions or exploit details in a public issue.

Only the latest published source release is maintained. No response-time or
bounty commitment is implied. Maintainers will validate the report and
coordinate a fix and disclosure where appropriate.

## Financial safety
This source release is not an audit, investment advice or authorization to
spend funds. No deployed address, live trading readiness, return or identity
attestation is implied. Mainnet execution requires verified contracts, feeds,
liquidity, permissions and explicit opt-in. Never use a funded key for tests.
Treat a signed transaction as sensitive until it is broadcast or invalidated.
